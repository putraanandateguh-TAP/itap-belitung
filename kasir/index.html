Fitur iTAP Kasir

📷 Scan transaksi pakai AI
Foto barang di meja kasir, AI kenali dan isi keranjang. Tanpa barcode.
🏷️ Tambah produk dari foto
Foto kemasan, nama & kategori terisi otomatis.
🚚 Kulakan
Catat belanja stok, HPP & harga jual ter-update.
📋 Stok opname
Hitung fisik terpandu, langsung kelihatan selisih & nilai rugi.
📊 Dashboard
Omzet vs kemarin, laba kotor, produk terlaris, alarm stok menipis.
🧾 Struk & laporan
Tunai/QRIS/transfer, hitung kembalian, struk via WA atau print, laporan CSV/PDF.
🔒 Data di HP sendiri
Tanpa server, tanpa daftar akun. Backup JSON kapan saja.
📲 Bisa dipasang
Tambah ke layar utama seperti aplikasi, jalan juga saat sinyal lemah (kecuali scan AI).

3 langkah mulai

1. Buka aplikasi, isi produk (atau pakai template menu).
2. Tempel API key Gemini gratis untuk fitur scan AI (opsional).
3. Jualan: foto atau tap produk, bayar, kirim struk.

Pertanyaan umum

Perlu internet?Kasir, stok & laporan jalan offline setelah sekali dibuka. Scan AI butuh internet.
Scan AI bayar lagi?Scan AI pakai API key Gemini milik kamu sendiri. Google memberi kuota gratis harian; kalau melebihi, biaya dari Google ditanggung pemilik key.
Data saya disimpan di mana?Hanya di browser HP kamu. Kami tidak menyimpan data penjualan. Gunakan Backup JSON rutin, karena hapus data browser = data hilang.
Bisa dipakai di beberapa HP?Satu kode untuk satu toko. Data tidak sinkron otomatis antar-HP; pindah data lewat Backup/Pulihkan.
Bisa cetak struk?Bisa lewat fitur print HP/printer thermal Bluetooth yang mendukung print dari browser, atau kirim struk via WA.
